## Getting Started as a Developer

1. Understand the [Architecture](../0-overview/1-architecture.md)
2. Set up a development workspace
3. Read the contributing guidelines
4. Pick an issue or improvement
5. Submit a pull request

## Development Workflow

:::{code-block} none
Fork repository
    ↓
Create feature branch
    ↓
Make changes
    ↓
Test locally
    ↓
Submit pull request
    ↓
Code review
    ↓
Merge
:::
